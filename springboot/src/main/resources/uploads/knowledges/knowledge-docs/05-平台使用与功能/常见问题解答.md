# 常见问题解答（FAQ）

> 本文档适用对象：所有平台用户

## 一、平台使用类

### Q1：如何注册账号？
点击右上角「登录」按钮，选择「注册」，填写用户名、邮箱和密码即可。

### Q2：忘记密码怎么办？
在登录页面点击「忘记密码」，通过邮箱重置密码。

### Q3：数据安全吗？
平台采用行业标准的加密和防护措施，用户数据严格保密。

## 二、功能使用类

### Q4：如何上传知识库文档？
进入「知识库」页面，点击「上传」按钮，选择 PDF、Word、Markdown 或 TXT 文件即可。

### Q5：支持哪些文件格式？
- PDF（.pdf）
- Word（.docx, .doc）
- Markdown（.md）
- 文本文件（.txt）

### Q6：如何切换AI模型？
在「对话」页面右上角，点击模型名称，从下拉列表中选择其他模型。

### Q7：对话历史保存在哪里？
对话历史自动保存在「对话」页面的左侧列表中，支持新建、切换和删除会话。

## 三、学习类

### Q8：如何制定学习计划？
1. 完成「能力测评」
2. 在「目标设定」中输入学习目标
3. 系统自动生成「学习路径」
4. 按路径执行每日任务

### Q9：如何跟踪学习进度？
在「学习路径」页面查看进度百分比，或在「首页」查看学习统计卡片。

### Q10：遇到不懂的问题怎么办？
在「对话」页面提问，AI将采用苏格拉底式引导，帮助你独立思考。

## 四、技术类

### Q11：平台使用什么技术架构？
- 后端：Spring Boot 3.5 + Spring AI 1.1.7
- 前端：Vue 3 + Vite
- 存储：Elasticsearch + Redis
- AI：Qwen-Max / DeepSeek-V4 / MiMo / Ollama（动态切换）

### Q12：知识库如何存储文档？
文档上传后，系统进行文本提取、分块、向量化，存储到 Elasticsearch 中，支持高效的语义检索。

## 五、问题反馈

如遇到平台使用问题或技术故障，可通过以下方式反馈：
1. 在「智能对话」中描述问题，AI将尝试解决
2. 联系平台技术支持（在「个人中心」查看联系方式）
