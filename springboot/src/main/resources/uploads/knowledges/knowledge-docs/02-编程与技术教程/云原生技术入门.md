# 云原生技术入门

> 本文档适用对象：希望了解和学习云原生技术的开发者

## 一、什么是云原生

云原生（Cloud Native）是一套技术体系和方法论，旨在充分利用云平台的优势，构建可弹性扩展、高可用、易于管理的现代化应用。

**核心支柱**：
1. **容器化**：将应用与依赖打包为轻量级容器
2. **编排调度**：自动化容器的部署、扩缩容和管理
3. **微服务**：将应用拆分为独立的服务单元
4. **声明式 API**：通过声明而非命令管理资源

## 二、容器化技术

### 2.1 Docker 基础

**核心概念**：
- **镜像（Image）**：应用的只读模板
- **容器（Container）**：镜像的运行实例
- **仓库（Registry）**：镜像存储和分发

**常用命令**：
```bash
# 镜像管理
docker pull nginx
docker images
docker build -t my-app .

# 容器管理
docker run -d -p 8080:80 nginx
docker ps
docker logs <container-id>
docker stop <container-id>
```

### 2.2 Dockerfile 示例
```dockerfile
FROM openjdk:17-jdk-slim
COPY target/app.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java", "-jar", "app.jar"]
```

### 2.3 Docker Compose
```yaml
version: '3'
services:
  web:
    build: .
    ports:
      - "8080:8080"
  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
```

## 三、Kubernetes

### 3.1 核心概念

| 资源 | 作用 |
|-----|------|
| Pod | 最小部署单元，包含一个或多个容器 |
| Deployment | 管理 Pod 的副本和滚动更新 |
| Service | 提供稳定的网络访问入口 |
| Ingress | 外部访问的路由规则 |
| ConfigMap | 管理配置数据 |
| Secret | 管理敏感信息 |

### 3.2 部署示例
```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: my-app
spec:
  replicas: 3
  selector:
    matchLabels:
      app: my-app
  template:
    metadata:
      labels:
        app: my-app
    spec:
      containers:
      - name: app
        image: my-app:latest
        ports:
        - containerPort: 8080
---
apiVersion: v1
kind: Service
metadata:
  name: my-app-service
spec:
  selector:
    app: my-app
  ports:
  - port: 80
    targetPort: 8080
  type: LoadBalancer
```
