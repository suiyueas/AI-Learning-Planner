# 机器学习核心概念速查

> 本文档适用对象：机器学习初学者、需要快速查阅概念的开发者

## 一、机器学习分类

### 1.1 监督学习
使用标注数据训练模型，预测未知数据的标签或值。

| 类型 | 目标 | 算法示例 |
|-----|------|---------|
| 分类 | 预测离散标签 | 逻辑回归、决策树、SVM |
| 回归 | 预测连续数值 | 线性回归、随机森林回归 |

### 1.2 无监督学习
使用无标注数据发现隐藏的模式和结构。

| 类型 | 目标 | 算法示例 |
|-----|------|---------|
| 聚类 | 将相似数据分组 | K-Means、DBSCAN、层次聚类 |
| 降维 | 减少特征数量 | PCA、t-SNE |

### 1.3 强化学习
通过与环境的交互学习最优策略。

## 二、核心算法

### 2.1 线性回归
- **用途**：预测连续数值（如房价预测）
- **公式**：y = wx + b
- **评估指标**：MSE、RMSE、MAE、R²

### 2.2 逻辑回归
- **用途**：二分类问题（如客户流失预测）
- **核心**：Sigmoid 函数将输出映射到 0-1 之间
- **评估指标**：准确率、精确率、召回率、F1、AUC

### 2.3 决策树
- **用途**：分类和回归
- **核心**：通过树状结构进行决策
- **优点**：可解释性强、直观
- **缺点**：容易过拟合

### 2.4 随机森林
- **用途**：分类和回归
- **核心**：多棵决策树的集成
- **优点**：抗过拟合、特征重要性评估

### 2.5 SVM（支持向量机）
- **用途**：分类问题
- **核心**：找到最优决策边界
- **核函数**：线性、多项式、RBF

### 2.6 K-Means
- **用途**：聚类分析
- **核心**：将数据划分为 K 个簇
- **关键参数**：K 值的选择（肘部法则）

## 四、机器学习流程

数据收集 → 数据预处理 → 特征工程 → 模型选择 → 模型训练 → 模型评估 → 模型调优 → 模型部署

## 五、常见问题

### Q1：过拟合与欠拟合

过拟合：模型在训练集上表现好，在测试集上表现差

欠拟合：模型在训练集和测试集上表现都差

解决方案：正则化、交叉验证、增加数据量

### Q2：特征工程方法

特征缩放：标准化、归一化

特征编码：One-Hot、Label Encoding

特征选择：方差阈值、特征重要性

### Q3：如何选择算法

数据规模：小数据 → SVM、大数据 → 深度学习

任务类型：分类/回归/聚类

可解释性要求：高 → 决策树/线性回归、低 → 深度学习
