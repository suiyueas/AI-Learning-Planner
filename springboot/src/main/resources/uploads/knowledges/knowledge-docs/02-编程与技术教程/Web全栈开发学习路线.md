# Web全栈开发学习路线

> 本文档适用对象：想系统学习Web全栈开发的学习者

## 一、全栈技术栈概览

前端（Vue.js） ←→ API 接口 ←→ 后端（Spring Boot） ←→ 数据库（MySQL）

## 二、前端学习路线

### 2.1 HTML/CSS 基础（第1-2周）
- HTML 标签与语义化
- CSS 选择器与盒模型
- Flexbox 与 Grid 布局
- 响应式设计（Media Queries）

### 2.2 JavaScript 基础（第3-4周）
- 变量、数据类型、运算符
- 函数、作用域、闭包
- DOM 操作与事件监听
- ES6+ 新特性（箭头函数、解构、模板字符串、Promise、async/await）

### 2.3 Vue.js 框架（第5-6周）
- Vue 实例与模板语法
- 组件化开发（props、emit）
- Vue Router 路由
- Pinia 状态管理

## 三、后端学习路线

### 3.1 Java 基础（第7-8周）
- 面向对象编程（类、继承、接口、多态）
- 集合框架（List、Map、Set）
- Lambda 表达式与 Stream API

### 3.2 Spring Boot 框架（第9-10周）
- Spring Boot 初始化与依赖注入
- Controller 与 RESTful API
- JPA 与数据库连接

### 3.3 数据库（第11周）
- MySQL 基础（CRUD、表关系）
- JPA 关联映射（OneToMany、ManyToOne）
- 分页查询与自定义查询

### 3.4 安全与认证（第12周）
- Spring Security 原理
- JWT 认证实现
- 角色权限管理

## 四、前后端整合

### 4.1 API 对接（第13周）
- Axios 请求封装
- 跨域处理（CORS）
- 登录注册功能对接

### 4.2 部署（第14周）
- Docker 容器化
- Linux 服务器部署
- Nginx 反向代理配置

## 五、项目实战

### 建议项目
1. **电商网站**：用户注册/登录、商品浏览、购物车、下单
2. **知识管理系统**：文档上传、分类、搜索、分享
3. **学习平台**：课程管理、进度追踪、问答社区

### 项目要求
- 前端使用 Vue.js
- 后端使用 Spring Boot
- 数据库使用 MySQL
- 包含完整的 CRUD 功能
- 有用户认证和权限控制
