# 智能体使用指南

> 本文档适用对象：想使用AI智能体功能的学习者

## 一、什么是AI智能体

AI智能体是一个能够**自主思考、规划、执行任务**的AI系统。它不同于普通问答AI，能够：

- **理解目标**：分析用户的高层级需求
- **自主规划**：将大任务拆解为多个小步骤
- **调用工具**：使用搜索引擎、知识库、PDF生成等工具
- **交付成果**：输出计划、报告、习题等具体成果

## 二、平台智能体类型

### 2.1 诊断Agent
- **职责**：能力测评、画像构建、薄弱点挖掘
- **使用场景**：了解自己的知识水平，定位学习短板
- **示例任务**：「帮我诊断一下Python水平」「评估我的数据分析能力」

### 2.2 规划Agent
- **职责**：路径生成、动态调整、资源推荐
- **使用场景**：制定个性化学习计划，优化学习路线
- **示例任务**：「制定一份3个月学习Python的计划」「调整我的学习路径」

### 2.3 答疑Agent
- **职责**：苏格拉底式引导、RAG检索
- **使用场景**：解答学习疑问，培养独立思考
- **示例任务**：「解释一下什么是闭包」「帮我理解递归函数的原理」

### 2.4 报告Agent
- **职责**：学情分析、报告生成、PDF导出
- **使用场景**：查看学习成果，生成学习报告
- **示例任务**：「生成我的月度学习报告」「分析我的学习数据」

### 2.5 搜索Agent
- **职责**：联网搜索、补充资料
- **使用场景**：获取最新学习资料和信息
- **示例任务**：「搜索机器学习入门教程」「查找Python数据分析项目案例」

### 2.6 干预Agent
- **职责**：行为监测、主动干预
- **使用场景**：学习提醒、预警、鼓励
- **示例任务**：「设置每日学习提醒」「分析我的学习习惯」

### 2.7 激励Agent
- **职责**：成就解锁、打卡管理
- **使用场景**：追踪学习里程碑，获取激励
- **示例任务**：「查看我解锁的成就」「今日学习打卡」

## 三、如何使用智能体

### 3.1 选择Agent
在「智能体」页面，点击任意子Agent卡片。

### 3.2 描述任务
在弹出的对话框中，用自然语言描述你想完成的任务。

### 3.3 观察执行
AI将展示完整的执行过程：
- 💭 **思考**：推理分析任务
- ⚡ **行动**：调用工具执行
- 👁️ **观察**：监控执行结果

### 3.4 获取结果
任务完成后，结果将展示在执行结果区域，支持复制和导出。

## 四、使用技巧

1. **清晰描述任务**：描述越具体，执行效果越好
2. **选择合适的Agent**：不同的Agent专注于不同领域
3. **观察执行过程**：了解AI的推理逻辑，提升自己的问题解决能力
