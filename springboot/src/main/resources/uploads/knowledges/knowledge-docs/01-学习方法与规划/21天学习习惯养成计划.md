# 21天学习习惯养成计划

> 本文档适用对象：希望建立持续学习习惯的学习者

## 一、习惯养成的三个阶段

心理学研究表明，新习惯的形成通常经历三个阶段：

### 阶段1：反抗期（第1-7天）
- **特点**：最容易放弃的阶段，身体和大脑都不适应新习惯
- **策略**：
  - 从极小的行动开始（如每天学习15分钟）
  - 不要追求完美，完成比完美重要
  - 使用打卡工具记录每日坚持

### 阶段2：不稳定期（第8-14天）
- **特点**：容易被突发情况打断，需要更强的意志力
- **策略**：
  - 建立「固定时间+固定地点」的学习仪式
  - 提前安排应对意外情况的预案
  - 加入学习社群，获得外部监督

### 阶段3：倦怠期（第15-21天）
- **特点**：感到单调和无聊，失去新鲜感
- **策略**：
  - 更换学习内容或方式，保持新鲜感
  - 设立阶段性奖励，激励自己继续
  - 回顾进步，增强成就感

## 二、每日学习打卡策略

### 2.1 设定最小学习量
设定一个「即使今天再忙也能完成的」最小学习量（如15分钟）。

### 2.2 固定学习时段
选择一个每天都能保证的固定时段（如早起30分钟或睡前30分钟）。

### 2.3 记录与反馈
- 使用平台的「进度追踪」记录每日学习情况
- 每周回顾学习数据，分析规律和问题
- 及时调整计划，避免中断

## 三、利用平台功能保持动力

### 3.1 「学习干预」功能
- 设置学习提醒，防止遗忘
- 接收AI的鼓励消息和预警通知
- 每周干预次数 ≤ 3 次，避免过度打扰

### 3.2 「学习成就」功能
- 解锁里程碑徽章（如「初露锋芒」、「持之以恒」）
- 连续7天学习 → 解锁「持之以恒」成就
- 掌握度≥90%知识点达到5个 → 解锁「学霸」徽章

### 3.3 「学情报告」功能
- 每周/每月自动生成学习报告
- 查看学习时长、进度、薄弱点
- 根据AI建议调整下一阶段计划

## 五、常见中断原因与应对

| 中断原因 | 应对策略 |
|---------|---------|
| 临时加班/考试 | 次日补足学习量，不连续中断超过1天 |
| 学习内容太难 | 使用「动态路径调整」降低难度，插入前置复习节点 |
| 失去动力 | 查看「学习成就」回顾进步，或「智能对话」寻求鼓励 |
| 时间不足 | 用「学习路径」功能调整每日学习量，压缩至最小可行量 |
