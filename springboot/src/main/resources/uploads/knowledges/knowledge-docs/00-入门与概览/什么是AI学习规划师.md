# 什么是AI学习规划师

> 本文档适用对象：潜在用户、首次了解平台的学习者

## 一、平台定位

AI学习规划师是一个**由大模型驱动的自主智能体学习平台**，旨在解决现代学习者面临的三大核心问题：

1. **知识体系碎片化**：零散学习缺乏系统性和连贯性
2. **缺乏系统路径**：不知道从何学起、如何进阶
3. **自学效率低下**：遇到问题无人指导，容易半途而废

## 二、平台能做什么？

### 2.1 精准诊断你的学习水平
- 通过主客观题测评，准确定位你的知识薄弱点
- 生成能力雷达图，可视化呈现你的学习现状
- 为后续学习路径规划提供数据基础

### 2.2 动态生成个性化学习路径
- 基于你的画像和目标，自动生成专属学习计划
- 根据学习进度实时调整路径，确保最优学习效果
- 覆盖从入门到精通的完整成长路线

### 2.3 苏格拉底式引导教学
- 不直接给答案，通过反问引导你独立思考
- 培养批判性思维和自主学习能力
- 提供适度提示，帮助你在困惑中找到方向

### 2.4 全周期学习陪伴
- 从诊断、规划、学习到报告，覆盖完整学习闭环
- 7×24小时智能监督和干预，保持学习动力
- 定期生成学情报告，追踪成长轨迹

## 三、适用人群

- **学生**：系统学习专业知识，备战考试
- **职场人**：提升技能，实现职业转型
- **终身学习者**：持续学习新知识，保持竞争力
- **自学者**：需要学习规划和指导的任何人

## 四、技术架构

平台采用先进的AI技术栈：

- **Spring Boot 3.5 + Spring AI 1.1.7**：稳定可靠的后端框架
- **ReAct Agent**：自主规划智能体，实现思考-行动-观察闭环
- **RAG（检索增强生成）**：基于知识库的精准问答
- **MCP（模型上下文协议）**：标准化的工具调用和扩展能力
- **多模型支持**：Qwen-Max、DeepSeek-V4、MiMo、Ollama 动态切换

## 五、与传统学习平台的区别

| 对比维度 | 传统学习平台 | AI学习规划师 |
|---------|------------|-------------|
| 学习路径 | 固定统一 | 千人千面，动态调整 |
| 教学方式 | 单向灌输 | 苏格拉底式引导 |
| 答疑方式 | 预设问答库 | 自主智能体实时解答 |
| 学习监督 | 无 | 7×24智能干预与激励 |
