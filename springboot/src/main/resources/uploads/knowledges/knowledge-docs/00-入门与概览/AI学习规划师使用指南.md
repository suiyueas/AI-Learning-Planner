# AI学习规划师使用指南

> 本文档适用对象：新用户、初次使用平台的学习者

## 一、平台简介

AI学习规划师是一个基于大模型的智能学习平台，通过自主智能体技术，为学习者提供**精准诊断、动态规划、引导式教学、全周期陪伴**的个性化学习服务。

平台核心理念是将传统「问答式AI」升级为「代理式AI」，模拟人类解决问题的思维方式：理解目标 → 分解任务 → 执行操作 → 观察结果 → 调整策略。

## 二、核心功能一览

| 功能模块 | 功能说明 |
|---------|---------|
| 智能对话 | 与AI助手进行苏格拉底式问答，获得个性化学习建议 |
| 工具中心 | 使用MCP工具进行知识图谱查询、资源检索、联网搜索等 |
| 知识库 | 上传学习文档，构建个人知识体系，支持RAG智能问答 |
| 智能体 | 调用7个专业子Agent完成诊断、规划、答疑、报告等任务 |
| 全部功能 | 查看和使用平台所有13个功能模块 |

## 三、快速上手流程

### 第1步：注册与登录
访问平台首页，点击右上角「登录」按钮，使用邮箱或手机号注册账号。

### 第2步：完成能力测评
进入「能力测评」页面，完成客观题和主观题的测评，系统将生成你的能力画像和掌握度雷达图。

### 第3步：设定学习目标
在「目标设定」中，用自然语言描述你的学习目标（如「3个月学会Python数据分析」），AI将自动解析并生成结构化目标。

### 第4步：生成学习路径
系统根据你的画像和目标，自动生成个性化学习路径，包含阶段划分、周计划和每日任务。

### 第5步：开始学习
按照学习路径逐日完成任务，AI将全程陪伴、答疑、追踪进度并动态调整计划。

## 四、页面导航说明

- **首页**：查看学习概览、统计数据、快速入口和精品学习路径
- **对话**：与AI助手进行深度交互，支持苏格拉底式引导提问
- **工具**：使用MCP工具进行知识图谱查询、资源检索、联网搜索等
- **知识库**：上传文档、管理知识、进行RAG智能问答
- **智能体**：调用7个子Agent完成复杂学习任务
- **全部功能**：浏览和使用所有13个功能模块

## 五、技术支持

如遇问题，可通过平台内的「智能对话」功能寻求帮助，或参考「常见问题解答」文档。
