## 1. 项目概述

### 1.1 项目背景

知途（Zhitu）是一款基于 Spring AI + RAG + MCP 的 AI 智能学习平台，“知途”寓意「知识之路」—— AI 辅助你走好知识之路。提供学习路径规划、知识库管理、AI 智能体对话、能力诊断等核心功能。当前前端存在以下问题：

- 多个 `.vue` 文件超过 1000 行（LearningPathDetail 1568 行、Home/LearningPathList/Agents 均超大），维护困难
- 页面间存在大量重复样式代码（卡片、进度条、背景粒子等），缺乏组件化抽象
- 顶部导航栏在多模块场景下导航效率低，功能分区不清晰
- 缺乏统一的 AI 对话交互体验，智能体中心功能虽强但 UI 简陋
- 响应式适配不完善，移动端体验差

### 1.2 重构目标

1. **布局升级**：从顶部导航栏切换为「侧边栏 + 主内容区 + AI 助手面板」三栏布局
2. **设计升级**：从赛博朋克重特效风转向 Vercel/Supabase 式清新科技风
3. **组件化**：彻底拆分超大组件，所有 `.vue` 文件控制在 300 行以内
4. **AI 交互升级**：集成 Element-Plus-X 组件库，打造专业级 AI 对话界面
5. **响应式**：桌面优先，移动端自适应

### 1.3 品牌标识

| 维度 | 规格 |
|------|------|
| **中文名** | 知途 |
| **英文名** | Zhitu |
| **Slogan** | AI 辅助你走好知识之路 |
| **品牌含义** | 「知途」= 知识 + 旅途，寓意 AI 引导学习者在知识之路上前行 |
| **Logo 风格** | 简洁的路径/道路图标 + 书籍/灯泡元素，Indigo 主色调 |

### 1.4 目标用户

- 在线学习者（学生、自学者、职业转型者）
- AI 辅助学习的教育工作者

## 4. 设计规范

### 4.1 视觉风格定位

**清新科技风**（参照 Vercel / Supabase / Linear）

- 简洁干净的卡片布局，无粒子/极光/扫描线等视觉噪音
- 精确的边框和阴影层次，而非大面积发光效果
- 蓝紫色点缀作为品牌色，保持科技感但不过度张扬
- 适度的圆角和内边距，舒适的视觉呼吸感

### 4.2 色彩系统（深色主题）

```scss
// === 背景层级 ===
$bg-base:       #09090b;     // 最深 - 页面底色
$bg-surface:    #18181b;     // 卡片/面板背景
$bg-elevated:   #27272a;     // 弹窗/下拉菜单
$bg-muted:      #3f3f46;     // Hover 态、禁用态

// === 边框 ===
$border-default: #27272a;    // 默认边框
$border-subtle:  #1e1e22;    // 更微妙的分隔
$border-focus:   #6366f1;    // 聚焦态边框（Indigo）

// === 文字 ===
$text-primary:   #fafafa;    // 标题/关键信息
$text-secondary: #a1a1aa;    // 正文
$text-muted:     #71717a;    // 辅助说明
$text-inverse:   #09090b;    // 反色文字（用于实心按钮上）

// === 品牌色 ===
$accent-indigo:  #6366f1;    // 主品牌色 - Indigo 500
$accent-violet:  #8b5cf6;    // 辅助品牌色 - Violet 500
$accent-cyan:    #06b6d4;    // AI/智能体强调色

// === 语义色 ===
$color-success:  #22c55e;    // 成功/已完成
$color-warning:  #f59e0b;    // 警告/进行中
$color-danger:   #ef4444;    // 错误/危险
$color-info:     #3b82f6;    // 信息提示

// === 发光效果（克制使用）===
$glow-focus: 0 0 0 3px rgba(99, 102, 241, 0.15);  // 焦点光晕
$glow-hover: 0 4px 12px rgba(0, 0, 0, 0.25);       // 悬浮阴影
```

### 4.3 排版规范

| 元素 | 字体 | 大小 | 字重 | 行高 |
|------|------|------|------|------|
| 页面标题 | Inter / Noto Sans SC | 24px | 600 | 32px |
| 区块标题 | Inter / Noto Sans SC | 18px | 600 | 28px |
| 卡片标题 | Inter / Noto Sans SC | 15px | 600 | 24px |
| 正文 | Inter / Noto Sans SC | 14px | 400 | 22px |
| 辅助文字 | Inter / Noto Sans SC | 13px | 400 | 20px |
| 小字/标签 | Inter / Noto Sans SC | 12px | 500 | 16px |
| 数据数字 | JetBrains Mono | 14px | 600 | - |

### 4.4 间距系统

基于 4px 网格：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64

### 4.5 圆角规范

| 元素 | 圆角 |
|------|------|
| 卡片/面板 | 12px |
| 按钮/输入框 | 8px |
| 标签/徽章 | 6px |
| 头像/圆形按钮 | 50% |

### 4.6 动效规范

- 页面切换：淡入淡出 200ms
- 面板展开/收起：滑动 250ms ease-out
- 卡片悬浮：translateY(-2px) + 阴影加深 200ms
- AI 打字效果：逐字显示 + 光标闪烁
- 加载骨架屏：微光动画 1.5s 循环

### 7.2 代码规范

1. **单文件行数限制**：每个 `.vue` 文件不超过 300 行
2. **模板/脚本/样式分离**：模板超过 100 行时，抽取子组件
3. **样式抽取**：超过 50 行的 scoped SCSS，抽取到 `styles/` 下的模块文件
4. **组件粒度**：一个组件只负责一件事（单一职责原则）
5. **Props 命名**：camelCase（JS 中）→ kebab-case（模板中）
6. **事件命名**：`update:xxx` 用于 v-model，`handleXxx` 用于操作事件
7. **JavaScript**：不使用 TypeScript，不使用 `<script lang="ts">`

### 7.3 Store 规范
